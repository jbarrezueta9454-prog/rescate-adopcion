# Control de Rescate y Adopción

Prototipo estructural en HTML5 semántico (sin CSS) de un sistema web para el control de rescate y adopción de animales.

- **Autor:** Juan David Barrezueta Parraga
- **Asignatura:** Desarrollo de Sistemas Informáticos, Universidad Técnica de Manabí
- **Actividad:** #3 Resolución de Ejercicios (Unidad II)
- **Periodo:** Septiembre 2026 - Enero 2027

## Estructura del proyecto

```
rescate-adopcion/
├── index.html      # Dashboard principal
├── reportar.html   # Formulario de nuevo animal rescatado
├── rescates.html   # Tabla y lista anidada de casos
├── README.md
└── assets/
    └── img/
```

## Ejecución

Abrir `index.html` en el navegador (o usar la extensión Live Server de VS Code) y navegar con el menú entre las tres páginas.

## Estándares

- Etiquetas semánticas: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Formulario accesible: `fieldset`, `legend` y `label` asociados con `for`/`id`.
- Validado con el Markup Validation Service de la W3C (https://validator.w3.org/).
